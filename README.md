# 中国旅行地图 · 江西原型

以江西11个地级市验证全国市级抽象旅行地图。v0.5默认使用共享边界的成组长线合并；左侧保留真实参考，右侧可切回旧版首次贴合和第1—9轮。

## 算法

从真实边界首次45°贴合结果出发，将共享边界拆成固定交会点之间的链，尝试用一两段长线替换一串短折线。按减少点数、短线数量、形状误差确定候选优先级。候选必须满足累计形状预算、接触和环绕顺序不变、有效覆盖、无重叠，并使全图实际转角严格减少。

固定顺序自动扫描，直到没有可接受替换。每次接受都降低整数转角数，因此保证有限终止，不需要人工指定优化轮数；这是给定替换规则下的局部停止，不保证全局最优。完整参数、候选规则、限制和全国迁移说明见 [ALGORITHM.md](ALGORITHM.md)。

## 使用

打开 `dist/index.html`。左侧是真实区划SVG；右侧默认“长线合并”，可选择历史轮次。两图使用相同投影、坐标和比例尺。

悬停或Tab选中可同步高亮，点击、回车或空格同步填色。切换版本保留颜色，白色擦除，清空按钮清除全部颜色。PNG导出当前抽象版本的完整1520×1720图像；左侧可下载参考SVG。刷新会清空颜色。

纯静态HTML/CSS/JavaScript，无浏览器运行依赖、无外部地图请求。GitHub Pages可使用main分支根目录，入口跳转到dist/，也可直接发布dist/。

## 生成与验证

```sh
pip install -r requirements-map.txt
python generate_map.py
python validate_geometry.py
```

生成命令会重建历史对照，然后自动生成默认长线版，无需手工重复运行。Shapely 2.1.2仅为生成和验证依赖。

验证实际交付的全部11个版本：11市、19对市际邻接、连通分量/孔洞/接触签名一致、无重叠、外框等于城市并集、标签在市内、方向均为45°倍数。另验证长线版的共享链来源、交会顺序、累计距离/面积/IoU预算，以及每次合并严格减少转角。旧第9轮固定点检查只针对历史版本，不用于宣称新版全局最优。

`dist/shortcut-report.json`保留新算法过程与几何来源；`dist/iteration-report.json`保留旧算法轮次。JavaScript语法和静态资源引用已检查，未执行浏览器交互及PNG下载测试。

## 全国范围约定

保留地级市及对应的自治州、地区、盟；直辖市各为一个市级单元，港澳各为一个单元，台湾按省级整体呈现。无所属地级区划的省直辖县级单位先独立保留。后续在真实形状基础上放大小区域，同时允许周围区域变形。

# 中国旅行地图 · 江西原型

全国市级抽象旅行地图的第一个局部实验：江西 11 个地级市。

## 使用

打开 `dist/index.html`，选择颜色并点击城市。白色用于擦除，支持键盘 Tab / Enter / 空格操作。导出按钮生成完整的 1520 × 1720 PNG，包含城市文字。当前颜色仅保存在页面内存中，刷新会清空。

纯静态 HTML / CSS / JavaScript，无运行依赖，也不需要服务端。GitHub Pages 可使用 main 分支根目录，根目录入口会进入 `dist/`。也可将 `dist/` 内容直接作为静态网站发布。

## 地图设计

- 原创正交网格布局，通过共享边界构成连续分区，避免各市独立简化产生裂缝。
- 美观、直观优先；保留主要方位和市际邻接，压缩区域面积差异。
- 当前 11 区面积最大/最小比为 4.75:1，放大新余、鹰潭、萍乡等小区域。
- 以宜春—南昌—上饶的中北部结构和吉安—抚州—赣州的南部结构组织布局。
- 景德镇通过上饶与省内其他城市分隔；新余与宜春、吉安接壤。
- 尚不表现湖泊、飞地、真实比例和精确省界；点接触不计作共享边界邻接。

`generate_map.py` 保存可编辑网格、标注位置、行政区代码及邻接约束。运行 `python generate_map.py` 可重建 `dist/map-data.js`。检查包含：区域连续性、无内部孔洞，以及 19 对市际邻接。

## 依据与校验

2026-09-07 读取阿里云 DataV.GeoAtlas 江西地级边界数据：
https://geo.datav.aliyun.com/areas_v3/bound/360000_full.json

通过不同区域共享的边界顶点提取 19 对邻接，和本原型的共享网格边进行比对，未发现新增或缺失。该比较受源数据精度及共享顶点判定方法限制，并非官方边界审定。外部原始坐标未嵌入产品；本图使用原创抽象坐标。

灵感来自 https://github.com/itorr/china-ex 的简化区域与点击标记体验。本原型未复制该项目的 SVG、字体、代码或素材。

## 后续全国范围约定

保留地级市及对应的自治州、地区、盟；直辖市各为一个市级单元，港澳各为一个单元，台湾按省级整体呈现。无所属地级区划的省直辖县级单位先独立保留。小区域原位放大，同时允许周围区域和省界变形。

当前重点为江西布局评审。全国数据、旅行分类、路线、日期、存档等不在本轮范围内。

## 本轮验证与限制

- 11 个城市全部生成，19 对共享边界与参考数据匹配。
- 所有文字锚点位于所属区域，所有区域连续、无孔洞。
- JavaScript 语法与静态资源引用检查通过。

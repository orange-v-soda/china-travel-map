# 中国旅行地图 · 江西原型

以江西 11 个地级市验证全国市级抽象旅行地图。当前为 v0.4：保持拓扑的 45°迭代规整。

## 本轮方法

从真实边界生成的轮廓简化版开始：首次贴合到水平、竖直、45°方向，然后反复执行“简化共享边界 → 再贴合”。每轮在同一共享线网上处理全部城市，避免独立修改城市边界造成裂缝。

每个候选结果都检查：

- 所有区域有效，无重叠，边界共享一致；
- 每个市的连通分量数、孔洞数与源数据一致；
- 全省并集的连通分量与孔洞数一致；
- 每对城市的接触类型（不接触、点接触、共边）与共边连通段数一致；
- 所有线段满足 0/45/90/135°方向约束。

九江的两个极小离散区域容易在常规网格量化中消失。本版在各自真实区域内部生成微小 45°菱形并固定保留，所有阶段均保留三个连通分量。

只有验证通过的候选才进入下一轮。若候选破坏拓扑，则回退并标记“拓扑约束停止”；若出现循环或达到 30 轮上限，也会如实记录，不把这些状态称为收敛。

## 使用

打开 `dist/index.html`。左侧是真实区划 SVG；右侧所有轮次均采用 45°规整，可选择首次贴合、第 1—9 轮逐步比较。两图使用相同投影、坐标和比例尺。

悬停或通过 Tab 选中城市可同步高亮，点击、回车或空格同步填色。切换轮次保留颜色；白色擦除，清空按钮清除全部颜色。导出保存当前轮次的完整 1520 × 1720 PNG；左图可下载独立参考 SVG。刷新会清空颜色。

纯静态 HTML/CSS/JavaScript，无浏览器运行依赖，无外部地图请求。GitHub Pages 可使用 main 分支根目录，入口进入 `dist/`；也可直接发布 `dist/`。

## 生成与验证

```sh
pip install -r requirements-map.txt
python generate_map.py
python validate_geometry.py
```

Shapely 2.1.2 仅为构建/验证依赖。初始轮廓简化容差为 6 SVG 单位，迭代容差为 12，主网格为 1；微小离散区域使用 0.001 的局部坐标精度。容差是 coverage_simplify 的面积相关阈值，并非最大位移承诺。

验证针对交付文件中的全部 10 个阶段：11 市、19 对市际邻接、连通性/孔洞/接触签名一致，无重叠，省域外框等于各市并集，标签锚点位于对应区域内，全部线段满足方向约束。最终 SVG 的额外一轮固定点复验通过。静态资源与 JavaScript 语法检查通过；尚未执行真实浏览器交互和 PNG 下载测试。

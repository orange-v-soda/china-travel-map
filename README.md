# 中国旅行地图 · 江西与浙江

以江西与浙江22个地级市验证全国市级抽象旅行地图。默认展示两省连续地图；已接受的江西v0.8及历史对照独立保留在 `dist/jiangxi.html`。

## v0.10：舟山三个岛群块

舟山以三个八边形岛群块概括92个源地块的空间分布，采用面积加权聚类。岛块适度放大，并只在间隔不足6单位时逐步拉开中心。三个块同属舟山市，同步高亮、填色与导出；真实参考完整保留。

这是一项明确的示意放大：舟山不再适用主岛IoU≥75%及面积误差≤15%的限制，报告保留实际误差及放大比例。其余21市和所有市际共边保持上版几何。每块8个转角，全部45°倍数方向、无锐角，不与大陆或其他岛群相接。规则实现在 `island_groups.py`，统一生成命令自动应用。

## v0.9：从固定江西边界连续扩展浙江

浙江真实区划沿用江西的投影与比例尺，复用上饶—衢州的共享省界。江西几何冻结；新省内的共享边统一优化，保留主体的相对位置和接触关系。

按用户要求，浙江每市保留最大连通主体，舟山保留主体岛，省略其他离散地块。左侧真实参考保留完整数据。形状预算以保留主体为基准，报告另列完整来源IoU；不能把过滤后拓扑保持解释为全部原始岛屿仍存在。

生成：`python build_east.py`。验证：`python validate_east.py`。输入源数据、投影与冻结江西快照在 `data/`；最终城市和共边统计在 `dist/east-report.json`。流程自动扫描到无可接受改善，不需要人工指定迭代轮数，也不设城市转角配额。

## v0.7：消除与主体脱节感较强的小凸起

赣州南端、吉安西南侧、上饶北侧原本都是相连的窄小凸起，并非额外离散面。旧版固定交会点导致部分凸起无法消除。新版允许三岔交会点小幅移动，三条共享边界同步重绘；不靠单独删除一个市的轮廓造成空洞。

赣州转角19→12、吉安18→11、上饶23→18；全图165→141。三市短于12 SVG单位的边从14→1（剩余位于吉安，是短台阶，不是独立地块）。全部城市仍无小于90°的内角，19对邻接、主体连通/孔洞和交会环绕顺序检查通过。共享边界联动会同时改变相邻城市。

省域IoU91.59%，最低城市IoU75.06%；各市面积误差≤15%。相对冻结的去尖角版，每条共享链及城市边界双向偏移≤24 SVG单位。形状更概括，可切回上一版对照。该阶段以目标城市短边数和全图转角数作为启发式目标，不声称检测出了所有类型的窄颈。

`compact_lobes.py`使用数据生成候选位置，没有手写这些凸起的坐标。`dist/compact-report.json`保留移动交点、原始/最终共享链、逐次目标值和城市统计。

## v0.6：忽略极小离散地块，优先去尖角

按用户最新要求，允许忽略小飞地/离散地块。仅过滤非主体连通分量，且其面积须同时小于所属市0.5%和全省0.01%；每市最大主体始终保留。本例过滤九江两个极小离散地块，左侧真实参考及旧版本完整保留。

优化顺序改为“锐角数量最少 → 实际转角数量最少”。对尖角截短、重排局部折线，并调整固定交会点附近第一段方向；必要时允许临时增加少量转角。共享边界统一修改，保持过滤后的拓扑和交会顺序，每次修改严格改善上述目标，自动结束。

结果：锐角15→0，总转角173→165（其中过滤地块直接减少8个转角）。11市全部无小于90°的内部角；9市不超过20个转角，宜春21、上饶23。轮廓仍全部为45°倍数方向。省域IoU92.43%，最低城市IoU75.06%，形状不是完全不变。

验证对过滤后的参考检查主体连通/孔洞/市际接触和交会顺序，保留19对市际共边。不是声称过滤前后的离散分量数相同。累计位移相对固定长线合并版最多8 SVG单位；各市面积误差≤15%、IoU≥75%。过程与残余锐角见 `dist/angle-report.json`。

## 算法

从真实边界首次45°贴合结果出发，将共享边界拆成固定交会点之间的链，尝试用一两段长线替换一串短折线。按减少点数、短线数量、形状误差确定候选优先级。候选必须满足累计形状预算、接触和环绕顺序不变、有效覆盖、无重叠，并使全图实际转角严格减少。

固定顺序自动扫描，直到没有可接受替换。每次接受都降低整数转角数，因此保证有限终止，不需要人工指定优化轮数；这是给定替换规则下的局部停止，不保证全局最优。完整参数、候选规则、限制和全国迁移说明见 [ALGORITHM.md](ALGORITHM.md)。

## 使用

打开 `dist/index.html` 查看两省连续地图，两图使用相同投影和比例尺。历史江西页面可选择历史轮次。

悬停或Tab选中可同步高亮，点击、回车或空格同步填色。切换版本保留颜色，白色擦除，清空按钮清除全部颜色。PNG导出当前抽象版本的完整2320×2040图像（两省页面）；左侧可下载参考SVG。刷新会清空颜色。

纯静态HTML/CSS/JavaScript，无浏览器运行依赖、无外部地图请求。GitHub Pages可使用main分支根目录，入口跳转到dist/，也可直接发布dist/。

## 生成与验证

```sh
pip install -r requirements-map.txt
python generate_map.py
python validate_geometry.py
```

生成命令会重建历史对照，然后自动生成长线版、去尖角版、主体整合版和默认共边简化版，无需手工重复运行。Shapely 2.1.2仅为生成和验证依赖。

验证实际交付的全部14个版本：11市、19对市际邻接、连通分量/孔洞/接触签名一致、无重叠、外框等于城市并集、标签在市内、方向均为45°倍数。另验证长线版的共享链来源、交会顺序、累计距离/面积/IoU预算，以及每次合并严格减少转角。旧第9轮固定点检查只针对历史版本，不用于宣称新版全局最优。

`dist/shortcut-report.json`保留新算法过程与几何来源；`dist/iteration-report.json`保留旧算法轮次。JavaScript语法和静态资源引用已检查，未执行浏览器交互及PNG下载测试。

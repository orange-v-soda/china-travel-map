# 中国旅行地图 · 江西原型

全国市级抽象旅行地图的第一个局部实验：江西 11 个地级市。

## 使用

打开 `dist/index.html`，左侧为真实区划参考图，右侧为抽象地图；窄屏上下排列。两图同步高亮、同步填色。抽象图默认使用 45°斜边，可切换原直角版，切换保留颜色。选择颜色并点击任意地图上的城市。白色用于擦除，支持键盘 Tab / Enter / 空格操作。导出按钮生成当前抽象边界样式的完整 1520 × 1720 PNG，包含城市文字。当前颜色仅保存在页面内存中，刷新会清空。

纯静态 HTML / CSS / JavaScript，无运行依赖，也不需要服务端。GitHub Pages 可使用 main 分支根目录，根目录入口会进入 `dist/`。也可将 `dist/` 内容直接作为静态网站发布。

## 地图设计

- 原创正交网格布局，通过共享边界构成连续分区，避免各市独立简化产生裂缝。
- 美观、直观优先；保留主要方位和市际邻接，压缩区域面积差异。
- 原直角版面积最大/最小比为 4.75:1，45°斜边版约为 5.22:1，均放大小区域。
- 新版沿共享边界统一处理转角，加入水平、竖直、45°斜向边；保留三岔边界节点，防止不同城市独立修角产生裂缝。当前仍基于首版布局，尚未按真实轮廓重新优化所有顶点。
- 以宜春—南昌—上饶的中北部结构和吉安—抚州—赣州的南部结构组织布局。
- 景德镇通过上饶与省内其他城市分隔；新余与宜春、吉安接壤。
- 尚不表现湖泊、飞地、真实比例和精确省界；点接触不计作共享边界邻接。

`generate_map.py` 保存可编辑网格、标注位置、行政区代码及邻接约束。运行 `python generate_map.py` 可重建 `dist/map-data.js`。检查包含：区域连续性、无内部孔洞，以及 19 对市际邻接。

## 依据与校验

2026-09-07 读取阿里云 DataV.GeoAtlas 江西地级边界数据：
https://geo.datav.aliyun.com/areas_v3/bound/360000_full.json

通过不同区域共享的边界顶点提取 19 对邻接，和本原型的共享网格边进行比对，未发现新增或缺失。该比较受源数据精度及共享顶点判定方法限制，并非官方边界审定。抽象图使用原创坐标；真实区划参考 SVG 使用该数据的全部边界点，投影后仅保留两位小数，不另做轮廓简化。

灵感来自 https://github.com/itorr/china-ex 的简化区域与点击标记体验。本原型未复制该项目的 SVG、字体、代码或素材。

## 后续全国范围约定

保留地级市及对应的自治州、地区、盟；直辖市各为一个市级单元，港澳各为一个单元，台湾按省级整体呈现。无所属地级区划的省直辖县级单位先独立保留。小区域原位放大，同时允许周围区域和省界变形。

当前重点为江西布局评审。全国数据、旅行分类、路线、日期、存档等不在本轮范围内。

## 本轮验证与限制

- 11 个城市全部生成，19 对共享边界与参考数据匹配。
- 所有文字锚点位于所属区域，所有区域连续、无孔洞。
- JavaScript 语法与静态资源引用检查通过。
- 尚未执行真实浏览器交互和 PNG 下载测试；导出文字使用浏览器系统字体。

## v0.2 真实区划对照与斜边

- `dist/jiangxi-reference.svg`：可独立打开或下载的真实区划参考图，带来源说明和城市名称。
- `dist/reference-data.js`：同一来源生成的地图路径，以行政区代码与抽象图关联。
- `generate_reference.py`：读取 GeoJSON，使用球面墨卡托投影、统一缩放生成 SVG 和浏览器数据。命令：`python generate_reference.py /path/to/360000_full.json`。不传路径时下载上述来源；网页运行不需要访问外部地图服务。
- 来源 SHA256：`ee9696faaca6e644fb0f1aebfc0bd800beb938dd2eb1737fcb8b244072405d9e`。获取日期不等于行政区划数据的版本日期，源数据未标明边界生效时间。
- 参考图保留原始地理形状，抽象图改变面积与轮廓。两图分别等比适配相同画幅，不使用同一地理比例尺，不能据其显示尺寸比较真实面积。
- 数据来源图用于视觉对照，非官方标准地图；数据来源归属阿里云 DataV.GeoAtlas，仓库代码许可不代表对第三方地图数据重新授权。

运行 `python validate_geometry.py` 检查两个版本：11 区标签均在区域内部，19 对邻接一致，无区域交叉或覆盖空隙；斜边版所有线段方向均为 0/45/90/135°。仍未执行真实浏览器交互和 PNG 下载测试。

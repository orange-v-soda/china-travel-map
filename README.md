# 中国旅行地图 · 江西原型

以江西 11 个地级市验证全国市级抽象旅行地图的布局与基本交互。

## 当前版本：从真实边界出发（v0.3）

地图由真实区划路径生成，不再从手工矩形网格绘制。左侧保留参考区划，右侧提供两种处理结果：

- **轮廓简化**：对所有城市的共享边界统一进行拓扑保持简化，去除细碎转折，允许任意方向线段，尽量保留城市形状和相对位置。
- **45°规整**：在上述简化结果上，把线段约束到水平、竖直或 45°方向；将共享线网重新节点化、划分为不重叠面，再按与简化区划的面积交叠归属城市。

两图使用相同的投影、画幅坐标和比例尺，可直接比较位移和轮廓变化。切换模式时保留颜色。当前优先保留地理形状，**尚未进行面积均衡**；小区域的放大需要在这一基础上继续优化。

## 使用

打开 `dist/index.html`。在任意地图悬停或用 Tab 选择城市，可同时高亮对应城市；点击、回车或空格填色。白色擦除，清空按钮清除全部颜色。

导出按钮保存当前抽象版本的完整 1520 × 1720 PNG；左图可下载独立参考 SVG。颜色只在当前页面内存中，刷新会清空。

纯静态 HTML/CSS/JavaScript，无浏览器运行依赖、无外部地图请求、无需服务端。GitHub Pages 可使用 main 分支根目录，入口跳转到 `dist/`；也可直接发布 `dist/`。

## 数据与重建

参考边界来源：阿里云 DataV.GeoAtlas，2026-09-07 获取：
https://geo.datav.aliyun.com/areas_v3/bound/360000_full.json

源数据 SHA256：`ee9696faaca6e644fb0f1aebfc0bd800beb938dd2eb1737fcb8b244072405d9e`。

`generate_reference.py` 根据 GeoJSON 生成 `dist/reference-data.js` 和 `dist/jiangxi-reference.svg`。使用球面墨卡托投影、统一缩放，保留边界点，坐标保留两位小数。生成命令：

```sh
python generate_reference.py /path/to/360000_full.json
```

省略路径会从来源下载。获取日期不等于边界生效日期，源数据未标明区划版本。参考图不是官方标准地图；第三方数据归属其来源，不因仓库代码许可证而重新授权。

抽象地图直接读取已保存的 `dist/reference-data.js`，不需要重新下载：

```sh
pip install -r requirements-map.txt
python generate_map.py
python validate_geometry.py
```

Shapely 仅为构建/验证依赖。`generate_map.py` 使用 coverage_simplify，当前容差为 6 SVG 单位；这是简化算法的面积相关阈值，不是最大位移承诺。45°规整网格为 1 SVG 单位。历史矩形版本保留在 Git 历史中，不再作为生成输入。

## 检查结果

| 项目 | 轮廓简化 | 45°规整 |
|---|---:|---:|
| 路径坐标点数（含闭合点、共享边界重复计数） | 452 | 1236 |
| 与参考省域轮廓的交并比 IoU | 98.52% | 98.11% |
| 各市 IoU 的最低值 | 90.99% | 88.60% |
| 最大/最小区域面积比 | 11.73:1 | 11.71:1 |

参考图坐标点数为 5200。IoU 是在同一投影画幅中的几何交并比，不是官方地图准确率，也不衡量全部视觉质量。

对实际交付的 SVG 路径检查：11 个城市、19 对市际共享边界与参考数据匹配；区域有效、无重叠，省域外框与所有城市的并集一致；全部标注锚点位于所属区域内；45°规整版线段满足方向约束。细小岛屿可能因量化合并或消失，未保证岛屿级拓扑完全保留。

JavaScript 语法与资源引用已检查；尚未执行真实浏览器交互和 PNG 下载测试。导出文字使用浏览器系统字体。

## 全国范围约定

保留地级市及对应的自治州、地区、盟；直辖市各为一个市级单元，港澳各为一个单元，台湾按省级整体呈现。无所属地级区划的省直辖县级单位先独立保留。小区域未来原位放大，同时允许周围区域变形。

灵感来自 https://github.com/itorr/china-ex 。本原型未复制其代码、SVG 或字体。当前重点是江西形状评审；旅行分类、路线、日期和存档不在本轮范围内。
